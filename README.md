# flashlight
Flashlight app for Android 2.3 Gingerbread, using the old java APIs. No bloat, all free.

![icon](https://github.com/volegnar/flashlight/blob/main/app/src/main/res/drawable/icon.png?raw=true)

# One activity, one button, one job

Turn off and turn on - the app is simple as that
- basic layout
- under 50KB of app.

# How it works:

1. Camera.open()
2. Camera.Parameters
3. FLASH_MODE_TORCH
4. Camera.release()

*uses the old API, might be compatible up to android 5*

# Compile

I used AIDE version 3.2.200108 to compile the apk

Made for Legacy Android enjoyers!
